goTag scenario dashboard

Simulates two satellites that start at the same point and position but diverge after a small velocity nudge (delta-v) -- e.g. a cubesat ejection -- and shows what a ground sensor would see: how far apart they get (km), how far apart they LOOK in the sky (deg), and how their RF signals Doppler-shift differently over time.

Pane 1 -- Variable setup

Delta-v (km/s) -- the velocity nudge that creates the companion object

Realistic values are roughly 0.001-0.01 km/s (1-10 m/s) in magnitude, e.g. a cubesat ejection or small debris-separation event. Position starts identical for both objects; only velocity changes at t=0.

Pane 2 -- Real + simulated orbit view

The primary object's track is the REAL ISS trajectory (live TLE, propagated with SGP4). The companion object's track is SIMULATED (derived by applying a small delta-v to the primary's velocity at t=0, then propagated with a simple two-body integrator). Both are labeled explicitly in the plots below so it's never ambiguous which line is which.

{% if plots %}

Priority plot. This is the companion's position MINUS the primary's position, in km, at each timestep -- i.e. "if you were sitting on the real ISS, where would the simulated companion appear to be, and how does that change over time?" Both objects start exactly coincident (origin, marked with an X) and the companion drifts away as the simulation progresses (color = elapsed time). This is the view that actually shows the divergence this project studies -- a few km of drift is invisible in absolute orbital coordinates (see the plot below), so we zoom into the relative frame instead.

Absolute orbit in Earth-Centered-Inertial (ECI) coordinates, for orientation ("yes, this is a real orbit around Earth"). Real (ISS, SGP4) is solid blue; Simulated (companion, two-body + Δv) is dashed red. At LEO scale (~7000 km from Earth's center) a few km of separation is visually imperceptible, so the two tracks will look like they overlap -- that's expected, and is exactly why the relative-position plot above exists.
